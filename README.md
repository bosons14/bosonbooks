# BosonBooks

Search for books by topic, keyword, title, author or ISBN, and get the details needed to buy them: title, author, publisher, year, ISBN and links to shops and libraries. It lists catalogue details only, not book contents.

It is one HTML file with nothing to install. Open `index.html` in a browser, or publish it with GitHub Pages.

Catalogue records come live from [Open Library](https://openlibrary.org) and [Google Books](https://books.google.com). Google allows few searches without an API key; if it stops responding, add a free key at the bottom of the page. The key and your saved list stay in your browser.
